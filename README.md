# 🍽️ Sabority API

API REST para la plataforma de recetas Sabority, desarrollada con Express y MongoDB.

## 🚀 Tecnologías
- Node.js + Express
- MongoDB + Mongoose
- JWT (autenticación)
- bcrypt (cifrado de contraseñas)

## 📦 Módulos
- Auth (registro y login)
- Usuarios
- Recetas
- Categorías
- Favoritos
